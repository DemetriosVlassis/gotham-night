# Gotham night

A dark vigilante-night look for the Claude desktop and mobile apps: blue-black surfaces, a signal-yellow accent, and an animated gothic city skyline behind the chat. All artwork is original and this is an unofficial fan-style theme, not affiliated with any company or character owner.

## What it does

- Dark color theme (dark mode only) with a yellow accent
- Animated backdrop: moon, clouds, gothic skyline, clock tower, bats, fog, a searchlight with a bat-shaped signal, and an optional rain and lightning storm
- A "night watch" band above the message box with turn and tool-call counts
- Themed "working" words and a status line entry
- A `/gotham` command

## Install

At the prompt of a terminal session:

```
/plugin install gotham-night --marketplace DemetriosVlassis/gotham-night
```

Answer `y` to add the marketplace, then pick a scope.

From a shell:

```
claude plugin install gotham-night --marketplace DemetriosVlassis/gotham-night
```

## Commands

| Command | What it does |
| --- | --- |
| `/gotham on` | Put the look on |
| `/gotham off` | Take the look off |
| `/gotham storm` | Rain and lightning on |
| `/gotham calm` | Clear night, no rain |
| `/gotham band` | Show or hide the night-watch band |
| `/gotham status` | What is on right now |

## Notes

The look draws in the desktop and mobile apps only. The terminal and editors keep their own look. Animations stop when the system asks for reduced motion.
